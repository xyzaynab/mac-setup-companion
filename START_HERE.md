# Start Here: Mac Setup Companion

Welcome. This companion helps you set up a calmer, more reliable way to work on your Mac—one small action at a time.

## Open the app

1. Open **Terminal**.
2. Paste these two lines, one at a time:

```sh
cd "/Users/zaynab/Documents/github/mac-setup-companion"
~/.bun/bin/bun run dev
```

3. Open the address Terminal shows you. It is normally [http://localhost:8080](http://localhost:8080).
4. Keep that Terminal window open while you use the app. When you are done, click in Terminal and press `Control-C` to stop it.

If it says something is missing, run this once in the same folder, then try again:

```sh
~/.bun/bin/bun install
```

## Your five-step first pass

Open **Start Here** in the app and work through these five actions. They are deliberately small.

1. **Orient** — In Finder Settings, show the Path Bar and filename extensions. Put Downloads and your current project folders in Finder’s sidebar.
2. **Retrieve** — Find one known file by name, then find it by a phrase inside it. Fix a search problem before building more around it.
3. **Reduce new clutter** — Choose a real Screenshots folder. Use a clipboard-only capture when you do not need a file.
4. **Make one queue** — Create a `Review` tag and a Finder Smart Folder for files carrying that tag.
5. **Automate one repetition** — Make one Shortcut for selected files. Test it on copies before attaching automatic triggers.

The goal is not to do everything today. First make a small system that you can see working.

## How to use the core manual

- Start with **Begin Core Setup** and move through the chapters in order.
- Each screen offers a brief orientation, a real action, and something observable to check afterward.
- Use **Next** when you are ready to move on. It never marks a task finished by itself.
- Choose **Mark complete** only after you have actually done the action.
- Notes are optional. Use them for your own folder names, decisions, or reminders.
- Companion guides are there when you need extra help. They will not disturb your place in the core manual.

## A few useful expectations

- The manual has 41 core chapters, from 00 through 40.
- Reference material is optional and does not affect your core progress.
- Your progress and notes are stored in this browser on this Mac. If you clear the browser’s site data, they may be removed.
- Nothing is sent to a server by the app when you use it locally.

## A good first session

Give yourself 20–30 minutes. Complete the five-step first pass, then open Chapter 00. Stop after you have one reliable next action—not when you have tried to perfect the whole computer.

If something feels unclear, use the companion linked from that chapter and write a short note about what you observed. That is enough to keep moving.
